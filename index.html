En constante aprendizaje Construyendo una base sólida como desarrollador

Soy Andrés Robles, programador junior. Me interesa comprender cómo se construye una aplicación, desde lo que se ve en el navegador hasta la lógica del servidor y sus datos.

Practico con HTML, CSS y JavaScript, y también con React, Bootstrap y Tailwind CSS. En backend trabajo mi base con Java, PHP, Spring Boot, Spring Security y APIs REST, junto con PostgreSQL y MySQL.

Esta web es una plantilla de estudio para practicar diseño, estructura y organización del código. No representa una empresa, un catálogo de productos ni una lista de trabajos para clientes.

PerfilProgramador junior · en formación continua

Aprender construyendo, entender el código y seguir mejorando.

CÓMO APRENDO
01

Bases primero

Refuerzo HTML, CSS, JavaScript y Java para entender qué hace el código antes de apoyarme en una herramienta.

02

Práctica constante

Hago ejercicios de interfaces, componentes y formularios con React, Bootstrap y Tailwind CSS.

03

Conectar las piezas

Practico APIs REST, Spring Boot, Spring Security y PHP para relacionar la interfaz con la lógica y las bases de datos.

04

Revisar y mejorar

Leo documentación, reviso errores y reorganizo lo que aprendo. No busco aparentar experiencia que todavía estoy construyendo.
